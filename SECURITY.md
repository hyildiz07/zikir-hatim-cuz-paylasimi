# Security Policy

Bu repo yalnızca public-safe PWA/TWA kaynak dosyaları içindir.

## Yasak dosyalar

- `signing.keystore`
- `signing-key-info.txt`
- `*.keystore`
- `*.jks`
- `*.p12`
- `*.pem`
- `*.aab`
- `*.apk`
- `keystore-base64.txt`
- `.env`

## Not

`assetlinks.json` içindeki SHA-256 fingerprint public doğrulama bilgisidir; private key değildir.
